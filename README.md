🍕 Pizza Sales Analytics Dashboard | SQL + Power BI

📌 Project Overview

This project analyzes one year of pizza sales data using SQL and Microsoft Power BI to provide actionable business insights. The dashboard helps track key sales KPIs, identify customer ordering patterns, and evaluate the performance of pizza categories and products.

The project demonstrates data extraction, data cleaning, data transformation, data modeling, DAX calculations, and interactive dashboard development.

---

## 🎯 Business Objectives

- Monitor overall sales performance
- Analyze daily and monthly sales trends
- Identify best-selling and worst-selling pizzas
- Compare sales across pizza categories and sizes
- Provide interactive dashboards for business decision-making

---

## 🛠 Tools & Technologies

- SQL
- Microsoft Power BI
- Power Query
- DAX
- Data Modeling

---

## 📊 Dashboard KPIs

- Total Revenue
- Total Orders
- Total Pizzas Sold
- Average Order Value
- Average Pizzas Per Order

---

## 📈 Dashboard Features

### Home Dashboard

- KPI Cards
- Daily Order Trend
- Monthly Order Trend
- Percentage of Sales by Pizza Category
- Percentage of Sales by Pizza Size
- Total Pizzas Sold by Category
- Interactive Date Filter
- Pizza Category Slicer

### Best & Worst Sellers Dashboard

- Top 5 Pizzas by Revenue
- Bottom 5 Pizzas by Revenue
- Top 5 Pizzas by Quantity
- Bottom 5 Pizzas by Quantity
- Top 5 Pizzas by Orders
- Bottom 5 Pizzas by Orders

---

## 🔍 Key Insights

- Friday/ Saturday evenings recorded the highest order volume.
- July and January generated the maximum number of orders.
- Classic category contributed the highest revenue.
- Large-size pizzas generated the highest sales.
- The dashboard identifies top-performing and underperforming pizza products to support business decisions.
